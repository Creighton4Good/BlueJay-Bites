### Summary

#### Team Onboarding and Documentation Review

New team members were introduced to SCRUM processes, GitHub Kanban workflows, README documentation, database schemas, account information, and project communication expectations. The team emphasized open-source development practices, documentation ownership, daily work logs, and collaboration. New team members were provided with Google Drive access. New team members were informed of best practices for pull request review.

#### CI/CD and Development Workflow

The CI/CD pipeline was identified as the highest-priority task and was reported as completed using GitHub Actions. The team discussed pull request review requirements, branch management practices, and plans to track remaining CI/CD work through project management artifacts.

#### Development Updates

Timmy reviewed GitHub Actions, AWS documentation, database structure, and beginner-focused onboarding resources. Torin investigated Android support, Google Play Store requirements, administration tools, and build configuration issues related to EAS environment variables.

#### Kanban Board Updates

Catherine created a Prerequisite tag, as well as a High Priority tag. #### Application Demonstration

The team demonstrated the application to Dr. Fernandes and Dr. Weitl-Harms. Features reviewed included event maps with pins, event details, event management, notification settings, user roles which have differing views, administrative controls, event creation, dietary tags, scheduling fields, and photo uploads. The preview build was confirmed to be functioning without requiring the frontend to run separately.

#### Feedback and Enhancement Ideas

Suggested improvements included map navigation assistance, simplified selection controls through dropdown menus, organizer communication features, and future analytics or machine learning capabilities to personalize event recommendations.

#### Android and Distribution Planning

Android support was identified as the next major implementation focus. The team discussed Expo device registration requirements, development builds, Google Play distribution planning, and onboarding resources for future contributors.

#### Technical Blockers

The team reviewed several issues, including application connectivity problems on Creighton Wi-Fi, Maven dependency issues, development environment compatibility concerns, pull request review challenges addressing the frontend bug fixes, and onboarding challenges for new contributors. The team also discussed database access issues relating to AWS requiring a manual update of IP addresses.

#### Documentation Improvements

The group discussed strengthening onboarding materials, separating local and staging documentation, clarifying first-time setup instructions, documenting account-access procedures, and maintaining tutorial resources through GitHub Discussions.
